<h2>📌 Project Overview</h2>
<p>
This project analyzes coffee shop sales data using SQL to uncover meaningful business insights.
It simulates a real-world database system with multiple related tables such as Customers, Orders,
Menu, Employees, and Payments.
</p>

<p>
Using SQL queries, the project extracts key metrics like total revenue, customer behavior,
and popular products to support data-driven decision-making.
</p>

<hr>

<h2>🎯 Objectives</h2>
<ul>
  <li>Understand customer purchasing patterns</li>
  <li>Analyze total sales and revenue trends</li>
  <li>Identify best-selling products</li>
  <li>Improve business decision-making using data</li>
</ul>
